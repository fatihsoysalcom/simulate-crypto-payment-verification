# Simulate Crypto Payment Verification

This example demonstrates a client-side form for simulating cryptocurrency payment verification. Users input a transaction hash, which is then checked against a predefined reference ID and a mock correct transaction hash to simulate a successful or failed payment verification process.

## Language

`html`

## How to Run

Save the code as `index.html`. Open `index.html` in your web browser. Enter the mock correct transaction hash (provided in the code) to see a successful verification, or any other hash for a failed one.
